# 💻 Laptop Price Predictor

A Deep Learning-based web application that predicts laptop prices from their specifications using an Artificial Neural Network (ANN).

## 🚀 Live Demo

[Try the App](https://laptop-price-prediction-3mrszhbvcduqmwgxynkeex.streamlit.app/)

## 📌 Project Overview

This project uses an Artificial Neural Network (ANN) to predict laptop prices from specifications such as brand, laptop type, processor, GPU, RAM, storage, screen size, operating system, and weight.

The trained model is integrated with a Streamlit web application that provides an interactive interface for users to enter laptop specifications and receive an estimated price.
